# Phase 10 qualification

Phase 10 provides a derived Project Brain graph:

- folder/file topology comes from the repository index;
- node IDs are project/path scoped and layout is explicitly derived-only;
- authority files are visually classified without granting authority;
- snapshots can be rebuilt or deleted without changing canonical records;
- source revision and content hashes remain attached to graph nodes.

The graph is a read model and does not feed memory ranking, progress, MCP context, or agent reasoning.
