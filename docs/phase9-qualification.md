# Phase 9 qualification

Phase 9 adds deterministic intelligence primitives:

- project-scoped grouped search across repository metadata, activity, progress and memory;
- source-grounded Ask responses with durable source revision/hash citations;
- explicit `UNKNOWN` when no evidence matches;
- Since You Were Here checkpoints with explicit advancement and no silent erasure.

These read models do not create authority, directives or memory without explicit calls.
