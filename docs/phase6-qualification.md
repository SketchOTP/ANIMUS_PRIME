# Phase 6 qualification

Phase 6 exposes exactly the six canonical project-bound PRIME Memory MCP tools:

`prime_memory_store`, `prime_memory_recall`, `prime_memory_timeline`, `prime_memory_get`, `prime_memory_report_problem`, and `prime_memory_context`.

Grants bind project scope below request payloads, are revocable/expiring, and use bearer-token digests. The public surface has no bank administration or raw Hindsight tool. Context output is bounded and derived/provenance-labeled.
