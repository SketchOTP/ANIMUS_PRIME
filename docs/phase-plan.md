# §24A Phase Plan

The approved phase order is fixed: 0 source lock/contracts/threat model; 1 Core persistence/workflows/auth; 2 Nodes/repository read model; 3 onboarding/authority; 4 events/index/Git truth; 5 Hindsight memory; 6 MCP/AI connections; 7 Notion/documentation/operator experience; 8 GoalModel/progress; 9 Ask/Search/Home/activity; 10 Project Brain; 11 Evidence/Time Lens/Fork; 12 lifecycle/Tailscale/security; 13 reliability/backups/observability; 14 UX/installers/accessibility; 15 full qualification.

Only a recorded `PASS` with an exact qualified Git commit advances a phase. `FAIL` and `BLOCKED` are terminal for that phase until corrected and requalified.
